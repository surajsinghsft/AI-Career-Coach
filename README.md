SensAI ek AI-based web app hai jo users ko smart features provide karta hai jaise chat, quiz, aur learning tools.

## Features
- 🤖 AI Chat system
- 🧠 Quiz Generator
- 🔐 Login / Signup (Clerk)
- ⚡ Fast UI (Next.js)
- resume building


## Tech Stack
- Next.js
- React
- Tailwind CSS
- Prisma
- Gemini AI API

🚀 Installation
## Installation

1. Clone the repo
git clone https://github.com/your-username/sensai.git

2. Go to project folder
cd sensai

3. Install dependencies
npm install

4. Run project
npm run dev
